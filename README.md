# Grammar Agreement Card Game

A fun and interactive card game designed to help players master **noun-adjective agreement** and **subject-verb agreement** in English.

## 🎮 Features

- **Noun-Adjective Agreement**: Match adjectives with nouns they modify correctly
- **Subject-Verb Agreement**: Pair subjects with grammatically correct verbs
- **Progressive Difficulty**: Cards range from beginner to advanced
- **Score Tracking**: Keep track of your performance
- **Multiplayer Support**: Play with friends or against the computer

## 🚀 Quick Start

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/hugozado69-coder/grammar-agreement-card-game.git

# Navigate to the project
cd grammar-agreement-card-game

# Install dependencies
npm install
```

### Running the Game

```bash
# Start the development server
npm start

# Open your browser and navigate to:
# http://localhost:3000
```

## 🎯 Game Modes

### Mode 1: Noun-Adjective Matching
- Draw a noun card and match it with the correct adjective
- Example: "blue" with "sky"

### Mode 2: Subject-Verb Agreement
- Match subjects with verbs that agree in tense and number
- Example: "The cats" with "run"

## 📝 Card Format

Each card contains:
- **Word**: The main word
- **Difficulty**: Beginner, Intermediate, Advanced
- **Hint**: Optional hint to guide players
- **Type**: noun, adjective, subject, or verb
